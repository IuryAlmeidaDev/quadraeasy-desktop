Aplicação desktop em **Java** para agendamento de horários, controle de locações e gestão financeira de quadras esportivas e arenas.

---

## 📌 Sobre o Projeto

O **QuadraEasy Desktop** foi desenvolvido para simplificar a administração diária de centros esportivos. O sistema permite cadastrar quadras (futebol, tênis, vôlei, etc.), agendar horários avulsos ou mensalistas, controlar pagamentos e emitir relatórios de ocupação com interface visual intuitiva.

## 🚀 Funcionalidades

- 📅 **Grade de Horários:** Visualização rápida de horários livres, ocupados e reservados.
- 🏃 **Cadastro de Clientes e Mensalistas:** Controle de contatos e planos recorrentes.
- 💵 **Gestão de Caixa:** Registro de entradas, adiantamentos e pagamentos pendentes.
- 🗄️ **Persistência de Dados:** Armazenamento seguro de cadastros e agendamentos.

## 🛠️ Tecnologias Utilizadas

- **Java (Java SE)**
- **Interface Gráfica Desktop** (Swing / JavaFX)
- **Apache Maven**

## ⚙️ Como Executar Localmente

```bash
git clone https://github.com/IuryAlmeidaDev/quadraeasy-desktop.git
cd quadraeasy-desktop
mvn clean compile exec:java
```
